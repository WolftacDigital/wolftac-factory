# Font provenance and prerender proof

- Preserve upstream license bytes when a spec pins an exact source commit. `git diff --cached --check` can flag trailing spaces already present in OFL text. Re-download the pinned license, compare exact bytes/hash, and report those precise inherited findings; do not trim a license to make a whitespace check green.
- Distinguish actual HTML preload elements from Next Flight strings. Strip script/comment contents before parsing link tags; count and validate exact font URLs, type and crossorigin. Reject duplicate/missing/non-latin preloads.
- Verify generated-document exceptions by role, not filename. For a redirect require emitted redirect metadata and its Flight digest; for framework error pages require the status metadata plus recognizable error markup. Enumerate every HTML document and scan every document, including exceptions, for forbidden hosts. Keep exceptions limited to the reviewed spec.
- When a baseline qualification is required, build the exact base in a separate clean archive with normal font access, preserve stdout/stderr/exit and HTML hashes, then compare the actual redirect/error document roles and preload counts. Never infer baseline behavior solely from unchanged source. Obey bounded-attempt stop rules.
- Bind an issue-owned deny proxy to port 0 and record its actual port, PID/start time and log. Preserve curl-control logs separately before starting fresh build logs, otherwise successful negative controls contaminate the candidate's zero-request proof. Use a separate clean base archive for denied-host tests so a prior successful build cannot supply cached fonts.
- Close an owned Node proxy gracefully through parent-child IPC and `server.close`; do not terminate runtimes or borrow an existing listener. Keep the deny and logging semantics unchanged.
- Preserve failed local test logs when an unchanged verification run succeeds. Report the initial failures and later results separately; never describe a retry as a fix or use local retries to justify rerunning CI.
